# Expense Tracker - Quick Start Guide

Get started with Expense Tracker in 5 minutes.

## 1. First Launch (2 minutes)

### Grant Permissions
```
✓ Allow SMS Read/Receive
✓ Allow Notifications
```

### Set Billing Cycle
```
Settings → Cycle Start Day → Enter day (1-31) → Save
Example: 25 (if salary is on 25th)
```

### Set Budgets
```
Dashboard → Set Up Budgets → Enter amounts → Save

Recommended starting budgets:
- Food: 30,000 LKR
- Transport: 15,000 LKR
- Kids: 20,000 LKR
- Bills: 25,000 LKR
- Savings: 40,000 LKR
- Other: 10,000 LKR
```

## 2. Daily Use (30 seconds)

### Automatic Tracking
```
1. Make card payment or withdraw cash
2. Get notification from app
3. Tap notification
4. Select category
5. Done!
```

### Manual Entry
```
1. Tap + button
2. Enter amount
3. Select category
4. (Optional) Add description
5. Tap Add Transaction
```

## 3. Weekly Review (2 minutes)

```
1. Open Dashboard
2. Check remaining budget (big number at top)
3. Look for red/orange categories (over/near budget)
4. Tap category to see details
5. Adjust spending for next week
```

## Notification Types

| Notification | When | Action |
|-------------|------|--------|
| **Transaction Detected** | After SMS received | Tap to categorize |
| **Daily Reminder** | 8:00 AM | Review remaining budget |
| **Budget Alert** | At 80% usage | Consider reducing spending |
| **Budget Exceeded** | Over 100% | Stop spending if possible |
| **Cash Reminder** | 4/12/24 hrs after ATM | Categorize cash spending |

### Check Budget Status
```

```

### Add Expense
```

```

### Categorize Transaction
```
Tap notification → Select category → Done

```


## Budget Status Colors

- 🟢 **Green (0-79%)**: On track
- 🟠 **Orange (80-99%)**: Nearing limit
- 🔴 **Red (100%+)**: Over budget

## Emergency Quick Actions

### SMS Not Working?
```
Add transactions manually:
+ button → Enter details → Add
```

### Budget Exceeded?
```
1. Review transactions (History icon)
2. Stop non-essential spending
3. Use remaining budget wisely
4. Adjust next cycle's budget
```

### Forgot to Categorize?
```
1. History icon
2. Look for "Needs categorization"
3. Tap each transaction
4. Assign categories
```

### Need to Change Budget?
```
Dashboard → Settings → Budget Setup → Adjust → Save
```
